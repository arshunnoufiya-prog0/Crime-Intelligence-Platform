### [2F] graph-rag/app/cypher/templates.py
──────────────────────────────────────
ALL Cypher lives here as static, parameterized strings — never built
via string interpolation of user or LLM text.
```python
TEMPLATES: dict[IntentType, str] = {
  IntentType.FIND_FIR_BY_ID: """
      MATCH (f:FIR {fir_id: $fir_id})
      OPTIONAL MATCH (f)-[:REGISTERED_AT]->(ps:PoliceStation)
      OPTIONAL MATCH (f)-[:INVOLVES_ACCUSED]->(a:Person)
      RETURN f, ps.name AS police_station,
             collect(DISTINCT a.name) AS accused
  """,
  IntentType.FIND_FIRS_BY_CRIME_TYPE: """
      MATCH (f:FIR)
      WHERE toLower(f.crime_head) CONTAINS toLower($crime_head)
        AND ($district IS NULL OR f.district_name = $district)
      RETURN f ORDER BY f.registration_date DESC LIMIT 50
  """,
  IntentType.FIND_LINKED_FIRS: """
      MATCH (f:FIR {fir_id: $fir_id})-[:SIMILAR_PATTERN]-(linked:FIR)
      RETURN linked
  """,
  IntentType.FIND_SUSPECT_NETWORK: """
      MATCH (g:Gang {name: $gang_name})<-[:MEMBER_OF]-(p:Person)
      OPTIONAL MATCH (p)<-[:INVOLVES_ACCUSED]-(f:FIR)
      RETURN g, collect(DISTINCT p) AS members, collect(DISTINCT f) AS firs
  """,
  IntentType.FIND_BY_DIGITAL_EVIDENCE: """
      MATCH (f:FIR)-[:LINKED_PHONE]->(ph:PhoneNumber {number: $phone_number})
      RETURN f
      UNION
      MATCH (f:FIR)-[:LINKED_VEHICLE]->(v:VehicleNumber {plate: $vehicle_number})
      RETURN f
  """,
```

```python
    if classified.intent not in TEMPLATES:
```

```python
async def build_networkx_graph(rows: list[dict]) -> nx.Graph:
    G = nx.Graph()
    for row in rows:
        G.add_node(row["id"], **row["properties"], label=row["label"])
    for edge in edges:
        G.add_edge(edge["source"], edge["target"], type=edge["type"])
    return G

def compute_metrics(G: nx.Graph) -> dict:
    return {
        "degree_centrality":      nx.degree_centrality(G),
        "betweenness_centrality": nx.betweenness_centrality(G, k=min(len(G), 100)),
        "eigenvector_centrality": nx.eigenvector_centrality(G, max_iter=500),
        "communities": [
            list(c) for c in nx.algorithms.community.louvain_communities(G, seed=42)
        ],
    }
```

```python
2. IF classified.intent == UNSUPPORTED or confidence < 0.5:
     yield no_template_match_event(query); return   # no LLM call, no Cypher
```

## ZERO-HALLUCINATION CONTRACT — FOUR LAYERS

  Layer 1 — Retrieval (graph-rag/)
    Vector search: `score_threshold=0.65` hard drop.
    Template search: empty result set → `no_context_event`, STOP,
    no LLM call.
    Unclassifiable intent → `no_template_match_event`, STOP, no
    Cypher execution, no LLM call.

  Layer 2 — Routing (cypher/router.py + validator.py)
    The LLM never generates Cypher. It only classifies intent and
    extracts typed, validated entities. Every query executed against
    Neo4j comes from the static `TEMPLATES` dict — this eliminates
    Cypher-injection risk and query hallucination simultaneously.

  Layer 3 — Generation (inference/ + graph-rag/core/sampling.py)
    `temperature=0.0, top_k=1` → deterministic greedy decode for both
    intent classification and final summarization.
    API guard: reject `temperature > 0.5` without `X-Allow-Creative: true`.

  Layer 4 — Response parsing (graph-rag/ + backend/)
    Every LLM output (intent JSON, summary JSON) is parsed with a
    Pydantic model. Parse failure → structured error, never raw text.
    `answer: null` / `reason: "not_in_graph"` is a valid, correct
    response, not an error.
